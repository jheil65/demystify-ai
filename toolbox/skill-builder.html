Build your skill

A skill is a short set of directions written in plain words: when to use it, what steps to follow, and when to stop and ask a person. Fill in the boxes, or start from an example. Your words stay on this page. Nothing is sent anywhere.

This is how the AI decides whether to pick the skill up. Be specific.

Three ways to use your skill

    

      
📋
Paste it (works everywhere, free).Use the paste-in version as the first message of a new chat. Save it in your notes app so it is ready next time.

      
📁
Save it as a skill.Gemini and Claude let you add the skill file version in their skill settings, and ChatGPT keeps skills inside plugins. After that, the AI picks your skill up when a request matches. Menus differ by tool and plan.

      
🤝
Share it with your team.A skill is plain text. Put it in a shared document so colleagues can use the same directions, whichever AI tool each person has.

    

    
💬 Try this
Test your skill twice with two different requests. Did the AI follow every step? Did it stop and ask when it should have? Change one line and test again. Good skills are revised, not written perfectly the first time.
